# 飞牛 NAS（fnOS）配置指引

> 配合 dsh phone 的 NAS 同步功能使用。实现见 `DshSync.java` / `DshWebDavClient.java`。

---

## 一、飞牛 NAS 端需要开两个开关

### 1. 开启 WebDAV 服务

飞牛后台 → **系统设置 → 文件服务 → WebDAV** → 勾选「启用」

- HTTP 默认端口：**5005**
- HTTPS 默认端口：**5006**
- 记下实际端口（若你改过）

### 2. ⚠️ 给目标文件夹开「协议访问」权限（最容易漏的一步）

飞牛后台 → **文件管理 → 团队文件** → 找到你要用的文件夹 → 右键「编辑」

勾选 **「允许通过文件共享协议（SMB、WebDAV、FTP）挂载到其他设备上」**

> **不加这一步会表现为：能连上、认证也过了，但 PROPFIND 返回空目录。**
> 这是 fnOS 特有的安全机制，不是本项目的 bug。排查时先确认这一项。

### 3. 确认账号对该文件夹有读写权限

成员权限里，登录 WebDAV 的那个账号（或其用户组）要有**读写**权限。
只读权限的话，同步会静默失败（上传返回 403）。

## 二、连接地址怎么填

在 dsh phone 的「导出数据」面板 → NAS 同步区块里填：

| 场景 | 地址示例 |
|---|---|
| 局域网（推荐） | `http://192.168.1.10:5005` |
| 局域网 + HTTPS | `https://192.168.1.10:5006` |

- `192.168.1.10` 换成你 NAS 的实际 IP；
- **不要带末尾斜杠**（脚本会自动去掉，但写了也不影响）；
- **不要填成本机地址**。

> **不推荐把 WebDAV 端口暴露到公网**：HTTP 是明文传输，Basic 认证的密码等于裸奔。
> 需要外网访问请走飞牛的 **FN Connect**（见下）。

## 三、可用 FN Connect 实现外网访问（可选）

飞牛后台 → **系统设置 → 远程访问 → FN Connect**（需 fnOS ≥ v1.1.15）

高级设置里勾选「允许通过 FN Connect 远程访问 WebDAV 服务」，会得到形如
`dav.xxxx.fnos.net` 的专用地址。

在 dsh phone 里填 `https://dav.xxxx.fnos.net`，这样**在外面也能同步**，无需公网 IP。

> **注意**：本项目的定时同步在 `DshService`（前台服务）里跑。
> Android 进入 Doze 休眠后可能被限制网络访问，表现为"息屏久了不同步"。
> 这是系统行为，非bug；亮屏或保持前台时正常。

## 四、同步什么不同步什么（重要）

| 目录 | 是否同步 | 说明 |
|---|---|---|
| `.dsh/storages/` | ✅ | 会话索引、工作区数据 —— **这就是要跨端共享的** |
| `.dsh/profiles/` | ❌ | 含 `node_modules`、`cordis.yml`、平台二进制 |
| `usr/`（运行时） | ❌ | Termux 的 `.so` 与桌面端不通用 |

**绝对不要手动把整个 `.dsh` 目录去做双向同步。**
那些插件文件是**平台相关**的：Termux 的 `.so` 和 Windows 的 `.node` 无法互换，
整目录同步会把两端的插件环境互相破坏，且症状隐蔽（表现为"装好的插件突然失效"）。

---

## 五、冲突处理：保留双份，不静默覆盖

如果本地与 NAS 上同一个文件都被改过，同步会：

1. 把**本地**那份另存为 `workspace.conflict-<设备名>-<时间戳>.json`；
2. 然后拉取 NAS 上的版本作为最新。

这样做的理由：会话数据丢一份的代价远高于多留一个文件。
你会看到多个 `.conflict-*` 文件，自己挑要保留哪份合并即可。

> 冲突副本只留在本地，**不会上传到 NAS**（避免污染远端、也避免反复冲突）。

## 六、排查

| 现象 | 检查 |
|---|---|
| 提示「无法连接 NAS」 | IP/端口对不对；NAS 是否开着；手机与 NAS 是否同一局域网 |
| 提示「无法创建远端目录」 | 上面第 2 步的「协议访问」开关没勾 |
| 认证失败 | 账号密码错；该账号对文件夹**无读写权限**（只读会失败） |
| 提示「尚无会话数据」 | 还没在手机上产生过任何对话，先用一次 dsh 再说 |
| 连上了但不同步 | 看手机是否已退出 App —— 定时同步挂在 `DshService` 前台服务上 |
| 息屏后不同步 | Android Doze 限制，属系统行为，亮屏即可 |
| 日志线索 | `adb logcat -s DshSync` / `DshWebDavClient` |

## 七、桌面端（PC）怎么配合

本实现只做**手机端**。PC 端 DSH Desktop 的数据在 `%USERPROFILE%\.dsh\`
（结构同构，也是 `storages/workspace.json`）。

若要两端互通，PC 侧用任意 WebDAV 客户端把
`%USERPROFILE%\.dsh\storages\` 同步到 NAS 的同一目录即可
（rclone / Cyberduck / Windows 挂载都行）。**PC 侧同步时同样只同步 `storages/`**。

> 桌面端目前还没有内置同步器。如果需要，我可以照手机端这套实现一个
> （Node/Electron 侧写起来更简单，Windows 直接用文件系统 API 读写）。
